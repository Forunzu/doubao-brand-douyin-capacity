# 品牌策略采集与双维交叉分析（默认必须步骤）

本流程把调研从"内容结构导向"（抖音产能一手抽样）扩展到**品牌策略导向**，并将两个维度**交叉分析**，回答"品牌最近在往哪走、为什么这么发内容、内容供给缺什么"——用于向品牌推售内容生产类产品时，把切入点从"内容现状"上升到"品牌战略需求"。

## 核心原则

- **自己动手搜索**：品牌策略信息用通用搜索自行采集（近 6–12 个月、至少近半年），**不依赖用户/老板提供材料**。
- 用户/老板另给的内部材料（如会面作战手册）只是**补充**，并入分析，不替代自行搜索。
- 默认报告形态为**双维交叉报告**。

## 流程

### Step A · 品牌策略信息采集（自行搜索）

1. **搜索关键词**（多轮并行，品牌名 + 各维度）：
   - 品牌名 + 新品 / 上市 / 发布
   - 品牌名 + 战略 / 定位 / 转型 / 升级
   - 品牌名 + 代言人 / 品牌大使
   - 品牌名 + 财报 / 业绩 / 年报（上市公司）
   - 品牌名 + 营销 / 战役 / 联名 / 渠道
   - 品牌名 + 内容 / 达人 / 投放 / 电商
2. **参考来源**：品牌官网、上市公司公告/财报、发布会报道、行业媒体、品牌官方公众号/社媒文章。第三方通稿/榜单不作为唯一依据（可能过时或夸大），以官方与一手报道为主。
3. **提炼输出**（逐条记录日期与来源）：
   - **战略动作时间线**（近 6–12 个月）：新品发布/上市（发布会、开售日期、价格带、包装与定位描述）、代言人官宣、战略定位升级/品类迁移、关键营销战役与渠道大动作。
   - **品牌定位与人群**：当前品类心智、转型方向、核心人群与场景（如电竞/备考/加班/运动）。
   - **媒介与渠道组合**：投放平台（抖音/B站/小红书等）、渠道覆盖（电商/即时零售/官方小程序）。
   - **内容策略现状**：内容侧重（如达人测评/开箱/场景种草）、供给模式（达人为主 vs 自有生产）。
   - **窗口期/周期判断**：新品认知窗口、品类教育期、关键节点（如上市后三个月）。
4. **来源分级（必须标注）**：
   | 来源类型 | 示例 | 报告中的口径 |
   |---|---|---|
   | 一手抽样 | 抖音账号/内容逐条采样截图 | "一手抽样" |
   | 公开信息 | 官网、发布会报道、行业媒体、财报 | "公开信息" |
   | 内部材料 | 用户/销售团队提供的作战手册、分析 | "内部研判"（汇报品牌时通常不提来源，仅作为分析依据） |

**红线**：内部材料中的**销售话术、价格策略、谈判应答、禁区话术**属于作战内容，**一律不进入面向品牌的报告**；只提炼其中对品牌现状/需求的客观研判（战略动作、市场判断、需求点），并中性化为"可探讨的方向"。

### Step B · 双维交叉分析（核心增值步骤）

建立**策略重点 × 内容现状映射矩阵**，逐项找缺口：

| 策略重点（品牌要什么） | 内容现状（调研事实） | 交叉判断（缺口/机会） |
|---|---|---|
| 转型需要大量"让人看懂新产品"的内容 | 主号综艺切片占比 X%、新品/品类内容占比 Y% | 新品科普内容供给不足 → 缺口 |
| 新品刚上市要铺量+密度 | 经销商标准文案铺量、AI 模块2 几乎空白 | 批量高质量产出能力缺口 |
| 内容依赖达人、品牌自己可控的少 | KOL 测评/探店占 X% | 品牌自有、可稳定产出的内容缺口 |
| 产品参数说法要统一 | AI 内容易出数字错误（如含糖量两个版本） | 素材与数字口径管理需求 |

1. 列出品牌策略的每个核心判断（转型期、窗口期、达人依赖等）。
2. 找到对应内容调研数据（占比、量级、模块分布、账号结构）。
3. 输出 3–5 条**交叉发现**：每条 = 品牌要什么 + 内容有什么 + 缺什么（可探讨的引导方向）。
4. 结论落点为**品牌内容需求的引导方向**，不写销售话术。

### Step C · 报告结构（双维交叉，默认）

双维交叉报告建议结构（9–11 页）：
1. 封面：品牌名 + 双维分析（内容产能 × 品牌策略）+ 时间区间
2. 品牌策略现状：战略动作时间线 + 定位升级/转型判断
3. 新品与市场：新品定位/价格带/渠道/内容侧重（公开信息）
4. 内容产能现状：账号量级 + 内容方向 + 产出节奏 + AI 模块（浓缩一手调研核心页）
5–7. 交叉发现 2–3 页：策略 × 内容映射（每条一页：品牌要什么 / 内容有什么 / 缺口）
8. 机会与可探讨方向：对应缺口的中性化方向（新品科普内容、多场景量产、一致性管理、数字口径校验）
9. 收束：品牌内容需求引导结论

截图使用：内容侧截图（抖音）照旧分散进相关页；品牌策略侧以时间线/图表/文字呈现，无截图时不虚构。
