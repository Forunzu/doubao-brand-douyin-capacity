# 品牌策略导向分析流程（brand-strategy dimension）

本流程把调研从"内容结构导向"（抖音产能一手抽样）扩展到**品牌策略导向**，并将两个维度**交叉分析**，回答"品牌为什么这么发、战略重点在哪、内容供给缺口在哪"——用于向品牌推售内容生产类产品时，把切入点从"内容现状"上升到"品牌战略需求"。

## 适用场景

- 用户/销售团队提供了品牌策略材料（如会面作战手册、品牌分析、行业简报）——本技能需一并纳入分析。
- 或用户只给品牌名，要求同时覆盖"品牌策略 + 内容产能"双维度（策略信息从公开渠道采集）。
- 默认报告形态升级为**双维交叉报告**（见 `report-spec.md` 的两种模式）。

## 流程

### Step A · 品牌策略信息采集

1. **战略动作时间线**（近 3–6 个月，逐条记录日期与事件）：
   - 新品发布/上市节点（发布会、全渠道开售日期、价格带、包装/定位描述）
   - 代言人官宣与品牌资产动作
   - 战略定位升级、品类迁移、集团战略规划表态
   - 其他关键营销战役/联名/渠道大动作
2. **品牌定位与人群**：当前品类心智、目标迁移方向、核心人群/场景（如电竞/备考/加班/运动）。
3. **媒介与渠道组合**：投放平台（抖音/B站/小红书等）、渠道覆盖（电商/即时零售/官方小程序）。
4. **内容策略现状**：内容侧重（如达人测评/开箱/场景种草）、内容供给模式（达人为主 vs 自有生产）。
5. **窗口期/周期判断**：新品认知窗口、品类教育期、关键节点（如上市后三个月）。

**来源分级（必须标注）**：
| 来源类型 | 示例 | 报告中的口径 |
|---|---|---|
| 一手抽样 | 抖音账号/内容逐条采样截图 | "一手抽样" |
| 公开信息 | 官网、发布会报道、行业媒体 | "公开信息" |
| 内部材料 | 用户/销售团队提供的作战手册、分析 | "内部研判"（汇报品牌时通常不提来源，仅作为分析依据） |

**红线**：内部材料中的**销售话术、价格策略、谈判应答、禁区话术**属于作战内容，**一律不进入面向品牌的报告**；只提炼其中对品牌现状/需求的客观研判（战略动作、市场判断、需求点），并中性化为"可探讨的方向"。

### Step B · 双维度交叉分析（核心增值步骤）

建立**策略 × 内容映射矩阵**，逐项找缺口：

| 策略重点（品牌要什么） | 内容现状（调研事实） | 交叉判断（缺口/机会） |
|---|---|---|
| 品类迁移需海量解释型内容 | 主号综艺切片占比 X%、新品/品类内容占比 Y% | 品类教育内容供给不足 → 缺口 |
| 新品窗口期需铺量+密度 | 经销商标准文案铺量、AI 模块2 几乎空白 | 批量高质量产出能力缺口 |
| 内容依赖达人、可控性差 | KOL 测评/探店占 X%、达人产能受限 | 品牌一致性/可控供给缺口 |
| 声称口径需合规管理 | AI 内容易出数字错误（如含糖量两个版本） | 声称校验/素材管理需求 |

1. 列出老板/策略材料的每个核心判断（品类迁移期、窗口期、达人依赖等）。
2. 找到对应内容调研数据（占比、量级、模块分布、账号结构）。
3. 输出 3–5 条**交叉发现**：每条 = 策略要什么 + 内容有什么 + 缺什么（可探讨的引导方向）。
4. 结论落点为**品牌内容需求的引导方向**（品类教育内容规模化 / AI 规模化应用 / 素材管理与数据归因 / 一致性底座），不写销售话术。

### Step C · 报告结构升级（双维模式）

双维交叉报告建议结构（9–11 页）：
1. 封面：品牌名 + 双维分析（内容产能 × 品牌策略）+ 时间区间
2. 品牌策略现状：战略动作时间线 + 定位升级/品类迁移判断
3. 新品与市场：新品定位/价格带/渠道/内容侧重（公开信息）
4. 内容产能现状：账号量级 + 内容方向 + 产出节奏 + AI 模块（浓缩一手调研核心页）
5–7. 交叉发现 2–3 页：策略 × 内容映射（每条一页：策略要什么 / 内容有什么 / 缺口）
8. 机会与可探讨方向：对应缺口的中性化方向（成分教育内容、多场景量产、一致性底座、声称校验）
9. 收束：品牌内容需求引导结论

截图使用：内容侧截图（抖音）照旧分散进相关页；品牌策略侧以时间线/图表/文字呈现，无截图时不虚构。
