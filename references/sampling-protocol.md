# 抽样协议（数量不可穷举 → 比例区间）

## 核心口径（用户锁定）

- 全量数量不可能穷举，**最好的方式就是抽样**。
- 输出一律为**比例区间**：
  - 下限 = 已确认数 / 样本量（或总量估算）
  - 上限 = 含疑似数 / 样本量（或总量估算）
- 抽样规模与范围在报告中**不体现为执行明细**（那是执行动作，不是品牌汇报内容）；只在技能内部记录。

## 抽样规模基线

| 对象 | 抽样规模 | 说明 |
|---|---|---|
| 官方主账号 | 滚动采样 4–5 屏 | 含作品列表逐条记录（ID/文案/时间/点赞/AI 标识） |
| 官方旗舰店/子账号 | 2–4 屏 | 产品种草+促销+联名为主，验证店铺层内容模式 |
| 账号矩阵（搜索用户 Tab） | 1 屏 | 盘点蓝 V 官方号 + 同名个人号结构 |
| 矩阵各类代表账号 | 每类 1–3 个账号 × 2–4 屏 | 经销商/职人重点记录发布频率与重复铺发模式 |
| KOL/达人 | 3–5 屏（约 20–30 条） | 按内容角色分类统计占比 |

## 抽样执行顺序

1. 官号主页头部截图（量级证据）→ 官号作品列表 4–5 屏采样（内容方向/频率/AI 标识）。
2. 搜索品牌名 → 用户 Tab 截图（矩阵结构）→ 按类抽代表账号。
3. 每类代表账号：主页头部截图 + 2–4 屏作品采样（内容模式/发布频率/点赞量级）。
4. KOL 通道切换（见 risk-control.md）采样 3–5 屏。
5. 对采样到的 AI 相关内容逐条做三模块判定（见 ai-module-judging.md）。

## 证据规范

- 每张截图命名：`{账号语义}_{YYYYMMDD}.png`，按账号语义分目录保存。
- 每个统计结论可回溯到具体截图与视频 ID（报告用截图佐证，技能内部用视频 ID 佐证）。
- 报告内**每张截图只使用一次**；需要表达多个点时，用一张图描述不同内容，或截新图。

## 比例区间换算示例

全矩阵约 1,630 条（各账号作品数之和口径）中：
- 模块 1 确认 1 条 → 下限 = 1/1630 ≈ 0.06%；含疑似 2 条 → 上限 = 2/1630 ≈ 0.18% → 输出"0.06%–0.18%"。
- 模块 2 疑似 1 条 → "约 0.06%"（几乎空白）。
- 模块 3（其余全部）→ 约 99.76%（= 100% − 0.18% − 0.06%）。
