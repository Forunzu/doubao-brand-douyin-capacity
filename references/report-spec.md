# 报告规范（品牌视角 · 可直接对外汇报）

## 交付形态

- **HTML 单文件**，按 PPT 比例排版（**严格 16:9**，用户会嵌入自己的汇报 PPT）。
- 采用 PPT 分模块叙事：封面 → 账号量级 → 内容方向 → 产出节奏 → 账号矩阵 → 经销商/职人 → KOL → AI 模块 → 总结与可探讨的优化方向。
- 推荐使用 HTML PPT 技能体系（如 guizang-ppt-skill 瑞士风 / frontend-slides）保证版式质量；自建版式时必须用固定舞台（如 `padding-top:56.25%` 或固定 1920×1080 缩放）锁死 16:9，**禁止元素把页面撑开变形**。

## 措辞（用户两次纠偏后的硬规则）

| 禁止 | 改为 |
|---|---|
| "他们/我们" 汇报腔 | 品牌方视角：直接陈述发现（"主账号综艺切片占比约 74%"） |
| 采样明细/执行动作（翻了几屏、怎么防验证码、@提及 ID 过程） | 不出现；ID 只作为可核验证据的内部保留 |
| 销售意义、以量取胜、切入机会等销售话术 | "可探讨的优化方向"（内容生产效率 / AI 规模化应用 / 数据驱动归因） |
| 向用户汇报的口吻 | 一份用户可以直接拿去向品牌汇报的成品 |

## 内容结构（建议 9 页左右）

1. 封面：调研主题 + 时间区间 + 一手抽样/截图佐证声明。
2. 账号量级与分工：官方主号 / 官方旗舰店 / 经销商代表账号的量级（作品/粉丝/获赞）。
3. 内容方向占比：综艺切片、产品与代言人、借势、联名共创、AI 相关（横向条形图）。
4. 产出节奏：主账号综艺期 vs 非综艺期、店铺/经销商月均发布量（KPI 塔）。
5. 账号矩阵结构：蓝 V 官方层 + 同名生态层。
6. 经销商/职人：大产量、标准化铺排、点赞量级（截图佐证）。
7. KOL 生态：测评 / 探店 / 带货 / 垂类四类占比。
8. AI 生产模块：模块 1 / 2 / 3 占比（比例区间），标注几乎空白的模块。
9. 收束：三条 takeaway + 可探讨的优化方向。

## 截图使用

- 每张截图**只出现一次**；表达多个点时用一张图描述不同内容，或截新图。
- 截图加简短文字备注（账号、量级、该图支撑的结论）。
- 截图必须真实来自调研过程（浏览器截图），不做虚构。

## 比例区间口径

- 所有占比给区间（下限=确认 / 上限=含疑似），并注明样本口径（如"采样 164 条""全矩阵约 1,630 条"）。
- 数字必须来自采样记录或可复现计算，不编造。

## 交付前自检清单

1. 浏览器渲染逐页核对：16:9 不变形、无大面积留白、无元素溢出/遮挡。
2. 每页一个主题，字号对比明显，中文大标题不超过 12 字。
3. 截图不重复、每张有备注。
4. 全文无采样明细、无销售话术、无"我向你汇报"痕迹。
5. 比例区间与采样口径一致。
