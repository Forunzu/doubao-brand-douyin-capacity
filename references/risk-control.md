# 风控基线（防验证码 · 实测结论）

本文件记录在抖音网页端实测得到的风控触发规律与对策。**目标是让"人+AI 协同采样"全程几乎不触发验证码**，而不是绕过验证码。

## 实测触发规律

| 行为 | 结果 |
|---|---|
| 固定节奏快速滚动 2–3 屏 | 触发"世界著名景点"图片拖拽验证码 |
| 未登录状态浏览作品列表 | 更容易触发风控 |
| 搜索页 `type=video` 批量翻页 | **一步命中验证码中间页**（冷却 10–15 秒仍被拦） |
| 登录态 + 随机节奏滚动 4–5 屏 | 实测 0 触发（旗舰店 4 屏 65 条、主号 3 屏 20+ 条） |
| 搜索"用户 Tab"逐页滚动 | 实测 0 触发 |
| 通用搜索直达 iesdouyin.com 分享页 | 无需登录、无验证码、web_fetch 可读 |

## 防触发操作规范（登录态会话）

1. **节奏随机化**：每次滚动间隔随机 2–5 秒；每次滚动量随机（3–7 个"屏"之间）。
2. **滚动幅度**：按页面高度分次滚（每次滚动高度随机），不要一次滚到底。
3. **登录优先**：能扫码登录就登录（扫码可接受），保持登录态会话。
4. **截图频率克制**：每 2–3 屏截 1 次，不要每屏都截。
5. **失败冷却**：若出现验证码中间页，停止该通道操作，冷却 10–15 秒；仍被拦则**切换通道**（见下）。

## 通道切换（搜索接口是唯一高风险点）

- KOL/达人/任意需要"按关键词找内容"的场景：**不要**走抖音站内搜索翻页，改用通用搜索（或浏览器直接搜索）命中 `iesdouyin.com/share/video/<id>` 分享页——无需登录、无验证码，`web_fetch` 可读标题、文案与部分发布时间。
- 已获得的视频 ID 一律可用 `https://www.iesdouyin.com/share/video/<id>` 做站外只读核验（判定 AI 标识、文案、时间）。

## 红线

- 不做自动识别/绕过图片验证码（拖拽验证码）。
- 扫码登录可接受、可让用户配合；**图片拖拽验证码不能频繁人工处理**——触发 1 次即视为该通道不可用，切换通道继续。
- 若两个通道都频繁触发，主动向用户说明并调整调研范围（缩小采样量），不硬扛。

## 参考样例

- 防触发节奏实测：旗舰店 4 屏 65 条、主号 3 屏 20+ 条、搜索用户 Tab 均 0 触发。
- 搜索 `type=video` 一步命中验证码中间页（高风险点）。
- iesdouyin 分享页样例：`https://www.iesdouyin.com/share/video/7394277484914642212`。
